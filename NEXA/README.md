## 🎯 Vision

NEXA is an AI-powered personal command center designed to help you:
- 🔍 Discover opportunities (scholarships, internships, fellowships)
- 💻 Manage software projects
- 💼 Develop business opportunities
- 📝 Organize important information
- ✅ Convert goals into concrete actions

## 🏗️ Architecture

```
GOAL → UNDERSTAND → RESEARCH → ANALYZE → PRIORITIZE → PLAN → ACT → TRACK → LEARN → IMPROVE
```

## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- MongoDB
- OpenAI API Key
- GitHub Account (connected)

### Installation

```bash
# Clone repository
git clone https://github.com/Cedrick-KC/NEXA.git
cd NEXA

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your credentials

# Run development servers
npm run dev
```
